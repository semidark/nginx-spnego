⚠️ Key concept — credentials: 'include'

Browsers do not send Kerberos / NTLM tokens on XHR or fetch() requests unless you explicitly opt in:

fetch(url, { credentials: 'include' })

Without this flag the browser sends no Authorization: Negotiate … header, the server returns 401, and SPNEGO negotiation never starts. Use the buttons below to compare both modes against the same endpoint.
